## 完整说明（最多 4000 字）

隅光是一款纯粹的本地图片切分工具：选择一张照片，设定网格与白边，一键导出可以直接发到社交平台的九宫格、四宫格或十二宫格图片。所有处理都在你的手机上完成，没有账号、没有广告、没有统计，隅光本身不会把照片上传到任何服务器。

主要功能：

• 多种宫格：支持九宫格、四宫格、十二宫格等切分布局，适合朋友圈、Instagram、小红书等平台的拼图发布。
• 构图调整：拖动照片调整主体位置，可选择裁满画面或保留完整原图。
• 白边与背景：统一调节每张切图的白边宽度和背景颜色。
• 画质可调：按需要选择导出质量，兼顾清晰度与文件大小。
• 批量保存：一键把全部切图存入相册；中途失败时会尝试清理本次已保存的图片。
• 系统分享：切完直接通过系统分享面板发送给好友或 App，分享文件按会话隔离，互不影响。
• ZIP 导出：把整组切图打包成一个 ZIP，方便一次性备份或转发。
• 大文件友好：针对超过 50MB、超高像素的照片给出明确提示，而不是莫名失败。

隐私与权限：

• 本地处理：隅光不申请网络权限，不包含任何广告、统计或登录 SDK。
• 仅读取主动导入的照片：通过 Android 官方照片选择器（Photo Picker）或剪贴板导入读取你主动选择的图片，无法浏览完整相册。
• 临时缓存：导入副本通常会在解码结束后删除；下次准备分享时会清理超过 24 小时的旧分享缓存，Android 系统也可能自行清理缓存。
• 不备份偏好：关闭了系统云备份，主题和界面语言设置只保留在本机。

适合谁：

• 想用一张照片在社交平台拼出连贯九宫大图的人。
• 重视隐私，不希望照片被上传、不喜欢广告和追踪的用户。
• 需要在手机上快速完成切图、不想依赖电脑和在线工具的创作者。

如有问题或建议，可通过 GitHub Issues 或 Google Play 商品页列出的开发者联系方式反馈。
